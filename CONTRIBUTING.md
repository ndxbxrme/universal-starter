# Contributing

Read AGENTS.md and CODEX_PROJECT_SPEC.md. Preserve one vanilla SPA and route native APIs through the platform contract. Use Node 24/npm ci and exact dependency pins. Run npm run check, production builds, verify:repository and affected wrapper checks; label host/device/account blockers honestly. Never include signing files, passwords, personal diagnostics or machine addresses in commits/issues.

Review managed/shared file ownership in docs/template-and-upgrades.md before upgrades. Keep command/platform guides synchronized with actual scripts. Production signing, account changes, publishing and secret sync require owner approval. Add meaningful regression tests for boundary/security failures, not tests that simply restate implementation details.
