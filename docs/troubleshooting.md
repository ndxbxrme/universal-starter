# Troubleshooting

npm ci: use Node 24 and the committed lockfile. Do not force major dependency upgrades to resolve native errors. Check proxy/network access and use deps:check/audit; inspect compatibility in toolchain.md. Formatting drift after managed-file edits is corrected by config:sync/format and reviewed with Git.

Vite port busy: stop the previous dev process before starting dev:desktop/dev:android; servers use strict ports. Browser API unavailable/denied: secure localhost/HTTPS and user gestures are required, and some browsers lack notifications/share/vibration. Review site permissions; unsupported features remain disabled. Browser offline reload is not implemented. For Pages asset 404s, rebuild with the repository WEB_BASE and verify hash routes/manifest paths rather than changing native base settings.

Android: source/set JAVA_HOME and ANDROID_HOME and expose ADB on PATH. Build tools 35 may be installed by AGP even when API/build-tools 36 are present. Accept SDK licenses with your SDK manager. SDK XML-version warnings alone are not build failures. On small hosts serialize emulator/build runs; the project limits Gradle workers and Kotlin process use. /dev/kvm absence blocks acceleration. The implementation host's software API 34 emulator rebooted on boringssl-self-check-failed with two CPU models; app smoke could not run. Use an accelerated runner/KVM or a real phone instead of claiming a passing native test. See android-wireless.md for pairing, changing ports, VPN/firewall/client isolation and forced-stop live-reload recovery.

iOS: use macOS/Xcode 26+, installed simulator runtime and npm ci before Swift package resolution. Check xcode-select and first-launch setup. A Release build phase requires Node on PATH; when using Xcode GUI with nvm, set NODE_BINARY to an installed Node 24 binary in scheme/build environment or run the documented npm/xcodebuild command from the terminal. Do not add a remote production server to work around missing bundles. Signing failures require matching client team/identity/profile/export mode, not deleting/recreating the project. Simulator success does not prove physical-device/TestFlight readiness.

Electron: Linux needs a display (Xvfb on CI) and a working sandbox policy/helper. Never disable production sandboxing to silence launch errors. The implementation host uses its existing trusted Chrome helper through CHROME_DEVEL_SANDBOX; a cold launch can be slow. AppImage mounting may need FUSE or --appimage-extract-and-run. Review DEB dependencies for the target distro. macOS/Windows packages must be built/tested on their runners. OS notification denial may surface as a failed operation even when an API exists.

Credentials: use setup utility --help/--non-interactive, external absolute paths and hidden/environment secrets. Sensitive tool errors are intentionally suppressed; validate the path/alias/password/tool in the client's controlled environment without printing secrets. Missing signing inputs do not block unsigned development. GH sync requires existing protected environment/admin access and exact confirmation. Expired profiles/certs, lost upload keys and handoff recovery are covered in credentials.md. No store/account/publication success is implied by artifact downloads.
