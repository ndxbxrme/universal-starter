Original image: [keystore-wizard_2x.png](https://developer.android.com/static/studio/images/publish/keystore-wizard_2x.png). Retrieved 1 November 2026. Credit: Android Open Source Project / Google. It illustrates the fields, not the exact layout of every Android Studio version.
