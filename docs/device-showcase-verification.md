Generated-input audio is a test fixture only. Production uses MediaRecorder on web/Electron, Android MediaRecorder and iOS AVAudioRecorder. Unsupported capabilities remain explicitly unsupported. GPS is foreground-only; no background location permission is requested. Audio is local, bounded to 60 seconds and 8 MiB, with explicit playback/export/discard controls.

On iOS, preferences are registered in the system Settings app using Settings.bundle. Android provides a native preferences Activity and the standard app-preferences intent; whether Android Settings shows its link depends on the phone vendor. Android does not offer an equivalent arbitrary embedded Settings.bundle page.

To test on the phone, reconnect wireless debugging, run `adb devices -l`, then from app1 run `npm run android:install -- --device "FIRST_COLUMN_SERIAL"`. The serial is the first column only. For live reload use `npm run dev:android -- --host 192.168.0.115 --device "FIRST_COLUMN_SERIAL"`. Reinstallation is required to register the new native plugin and permissions. Open Interactions and explicitly grant foreground location/microphone access; check current/follow/stop location, record/play/export/discard audio, and native preferences. Repeat denial and backgrounding cases. Do not infer device acceptance from browser fixtures.
